# GRAINHOUSE FLOORING

A warm, material-led flooring website for **Grainhouse**, defined by oat white, deep walnut, and a quiet editorial serif — built around an interactive room visualiser that swaps floor finishes and a transparent price-per-square-metre table that includes fitting costs.

---

## 🪵 Tech Stack
- **Framework:** React 19 + TypeScript + Vite
- **Styling:** Tailwind CSS + PostCSS + Autoprefixer
- **Motion & Animations:** Motion (`motion/react` / Framer Motion)
- **Icons:** Lucide React
- **Typography:** Newsreader (Editorial Serif) & Inter (Modern Sans)
- **Confetti:** Canvas Confetti

---

## ✨ Key Features & Components

1. **Editorial Navbar:** Symmetrical 3-zone architecture with brand wordmark, smooth scroll links, direct phone line (`0115 555 0163`), and Free Survey booking.
2. **Hero Section:** Split layout with editorial serif H1, Nottingham & East Midlands provenance, 4 trust points, and FSC-certified European oak plank showcase.
3. **Room Visualiser (Effect 1):** Interactive room switcher with 5 timber & stone swatches (Natural Oak, Smoked Oak, American Walnut, Oak Herringbone, LVT Stone Effect), 0.45s cross-fade, re-mounting tabular price line, and live area cost estimator slider.
4. **Floor Types Guide:** 2x3 responsive cards detailing Solid Wood, Engineered Wood, LVT, Laminate, Parquet/Herringbone, and Wool Carpet with honest trade-offs of when it is the right choice and when it is not.
5. **Full Transparent Price List:** Supply & fitting listed per m² with live quote estimator and separate transparent extras (underlay, £18/m² self-levelling compound, disposal, beading, free furniture moving).
6. **Grain Scroll Strip (Effect 2):** 5 close-crop wood grain textures with shallow parallax translation on scroll and `prefers-reduced-motion` accessibility support.
7. **Subfloor Honesty:** The industry-first honest breakdown of subfloor surprises, 3-point protocol (We Stop, We Show You, Fixed Quote), and calibrated Protimeter moisture testing.
8. **5-Step Fitting Process:** From 40-min free survey to final clean, highlighting the critical 7-day in-room timber acclimatisation period.
9. **Care & Guarantees:** 25-year wear guarantee guidelines, material cleaning tabs, and the famous Steam Mop warning.
10. **Recent Projects:** Real East Midlands installations with area in m², product specifications, and actual days on site.
11. **Free Survey Booking Form:** Interactive booking with room count, area slider, current subfloor conditions, zero sales pressure pledge, and confirmation confetti.
12. **Walnut Footer:** 4 columns with FSC® C142880 certification, Nottingham showroom address (210 Alfreton Road, NG7 3NR), opening hours, and contact information.

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Open [http://localhost:5173/](http://localhost:5173/) in your browser.

### Production Build
```bash
npm run build
```
